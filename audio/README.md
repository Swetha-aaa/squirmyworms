# audio/

Your own audio files, one folder per category: `audio/pop/`, `audio/kpop/`, ...
Name files `Artist - Title.mp3` (m4a, ogg, wav, flac also work). Optional
`manifest.json` per folder overrides title/artist/album/year or sets a `start`
offset (seconds) for full-length files. Run with `MIXTAPE_PROVIDER=files`.

Only use files you have the rights to. Private, personal play only.
